# Oiia 1.1.3

The map timeline now understands `has_dlc`-gated ownership, matching how
vanilla ships DLC-dependent start setups (e.g. the East Asia rework in
No Compromise, No Surrender).

## Highlights

- **DLC condition selector**: the `has_dlc` conditions referenced by the loaded
  state histories become toggleable conditions; owner/controller fills are
  re-evaluated for the selected timeline point + DLC combination, matching the
  game's conditional state-history script
  (`IF = { limit = { has_dlc = ... } transfer_state_to = ... }`).

## Download

Install `oiia-1.1.3.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.3).
