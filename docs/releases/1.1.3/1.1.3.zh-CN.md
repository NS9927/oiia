# Oiia 1.1.3

地图时间线现在支持 `has_dlc` 门控的归属，与原版用 DLC 控制开局设定的方式一致
（如 No Compromise, No Surrender 的东亚重做）。

## 重点

- **DLC 条件选择器**：州历史中引用的 `has_dlc` 条件成为可勾选条件；按所选
  时间点与 DLC 组合重新计算归属（对应游戏的条件历史脚本
  `IF = { limit = { has_dlc = ... } transfer_state_to = ... }`）。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.1.3.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.3) 下载。
