# Oiia 1.0.1

新增项目创建与 Shadow 启动器工作流。

## 重点

- **HOI4 模组项目向导**（`New Project | Game Modding | HOI4 Mod`）：生成
  `descriptor.mod`、可选启动器 `.mod` 描述、README 与 `.gitignore`。
- **Shadow 播放集同步**（`Tools | Sync Shadow Playset`）：按 remote file ID
  或规范化内容路径将 PLS 的 HOI4 模组加载顺序匹配到 Shadow 的模组索引。
- **`HOI4 via Shadow` 运行配置**：通过同步的播放集启动 HOI4，并可选在控制台
  流式输出 `error.log`。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.0.1.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.0.1) 下载。
