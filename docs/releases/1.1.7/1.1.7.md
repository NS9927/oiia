# Oiia 1.1.7

Builds against Paradox Chronicle 3.0.3. The build toolchain moves to Kotlin
2.4.0 and IntelliJ Platform Gradle Plugin 2.19.0.

## Highlights

- **Paradox Chronicle 3.0.3**.
- **Build toolchain**: Kotlin 2.4.0 and IntelliJ Platform Gradle Plugin 2.19.0.
  Gson 2.14.0 is declared in the version catalog.

## Download

Install `oiia-1.1.7.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.7).
