# Oiia 1.1.7

适配 Paradox Chronicle 3.0.3。构建工具链升级到 Kotlin 2.4.0 与
IntelliJ Platform Gradle Plugin 2.19.0。

## 重点

- 适配 **Paradox Chronicle 3.0.3**。
- **构建工具链**：Kotlin 2.4.0 与 IntelliJ Platform Gradle Plugin 2.19.0；
  Gson 2.14.0 改由版本目录声明。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.1.7.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.7) 下载。
