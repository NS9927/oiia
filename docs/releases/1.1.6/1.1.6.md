# Oiia 1.1.6

DLC conditions in the map timeline now start unchecked, the initial render
matches the checkbox state, and hovering DLC-recolorued states no longer shows
an unknown country. Also adapts to Shadow's new directory layout and adds a tag
triggered build workflow.

## Highlights

- **DLC conditions start unchecked**: the initial render matches the checkbox
  state (unchecked = base ownership); checking applies the changes immediately.
- **Hover fixes**: hovering DLC-recolorued states (e.g. HBC/SIC) resolves the
  country name, highlight box and borders instead of showing an unknown
  country; country borders and highlights rebuild on timeline/DLC changes.
- **Shadow directory layout**: playset sync resolves
  `%APPDATA%\Posdaca\Shadow\<Game>` first, keeping the older layouts as
  fallbacks.
- **GitHub Actions workflow**: pushing a `v*` tag builds the plugin, runs the
  tests and attaches the plugin zip to a matching GitHub Release.

## Download

Install `oiia-1.1.6.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.6).
