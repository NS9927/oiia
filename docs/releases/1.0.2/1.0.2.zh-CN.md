# Oiia 1.0.2

适配 Oiia 到 Paradox Chronicle 3.0.0（原 Paradox Language Support）。

## 重点

- 支持 **Paradox Chronicle 3.0.0**（插件 id 仍为 `icu.windea.pls`）。
- 适配更名的 `CwtLocaleConfig` API（`id` -> `name`）。
- 更新插件更名与版本要求的英文和简体中文文档。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.0.2.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.0.2) 下载。
