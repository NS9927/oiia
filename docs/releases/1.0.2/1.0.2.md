# Oiia 1.0.2

Adapts Oiia to Paradox Chronicle 3.0.0 (formerly Paradox Language Support).

## Highlights

- **Paradox Chronicle 3.0.0** support (plugin id remains `icu.windea.pls`).
- Locale preference handling adapted to the renamed `CwtLocaleConfig` API
  (`id` -> `name`).
- English and Simplified Chinese documentation updated for the plugin rename
  and version requirement.

## Download

Install `oiia-1.0.2.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.0.2).
