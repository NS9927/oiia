# Oiia 1.1.4

National focus preview now follows the game's `prerequisite` grouping and joint
style, and dragging a focus no longer corrupts its script coordinates.

## Highlights

- **Prerequisite block grouping kept**: several `focus` entries in one block
  are OR (dashed joint), separate blocks are AND (solid joint). Hover text
  shows the same grouping, and a focus is hidden when any prerequisite block
  has no member in the current tree.
- **Drag coordinate fix**: dragging a national focus no longer concatenates
  coordinates (`x = 5` becoming `x = 55`) when Chronicle leaves the integer
  outside the property value range.

## Download

Install `oiia-1.1.4.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.4).
