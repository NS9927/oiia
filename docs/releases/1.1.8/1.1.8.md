# Oiia 1.1.8

Country colours in the map preview are read correctly again: `common/countries/colors.txt`
is honoured, HSV colours are no longer misread as RGB, and vanilla's uppercase `HSV`
spelling is understood.

## Highlights

- **`common/countries/colors.txt` works again**: it is meant to take priority over the
  country definition files, but no entry was ever resolved, so a mod that defines its
  colours only there fell back to a generated colour.
- **Every colour shape**: `rgb { … }`, `hsv { … }`, `hsv360 { … }`, a bare `{ r g b }`
  block, and vanilla's uppercase `HSV { … }`; the channel conversion is delegated to
  Paradox Chronicle.
- **`color_ui` stays off the map**: it is the counter colour, and
  `common/countries/*.txt` remains the fallback. State category colours are read the
  same way.

## Download

Install `oiia-1.1.8.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.8).
