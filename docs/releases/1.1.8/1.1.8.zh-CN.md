# Oiia 1.1.8

地图预览恢复正确读取国家颜色：`common/countries/colors.txt` 生效，HSV 颜色不再被当成 RGB，
原版使用的大写 `HSV` 也能识别。

## 重点

- **`common/countries/colors.txt` 重新生效**：它本应优先于单独的国家文件，但此前完全解析不出
  颜色，只在其中定义颜色的模组会退回随机色。
- **覆盖全部写法**：`rgb { … }`、`hsv { … }`、`hsv360 { … }`、裸块 `{ r g b }`，以及原版
  使用的大写 `HSV { … }`；通道换算委托 Paradox Chronicle。
- **`color_ui` 不参与地图**：它是兵牌颜色；`common/countries/*.txt` 仍作为回退。州类别颜色
  也改用同一套解析。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.1.8.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.8) 下载。
