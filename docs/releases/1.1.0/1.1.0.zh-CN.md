# Oiia 1.1.0

全部脚本结构解析重建于 Paradox Chronicle 的 PSI 之上，科技树预览对齐游戏树布局。

## 重点

- **PSI 化解析**：移除手写文本解析器与正则 `.gfx` 精灵扫描，全部 Paradox
  脚本结构解析改走 PLS（Chronicle）PSI。
- **科技树对齐游戏**：文件夹内科技按 `leads_to_tech` 拆分为连通树，格距、
  主轴与格子尺寸读自 `countrytechtreeview.gui` 的对应 gridbox。
- **稳定性一轮**：后台线程解析与自动刷新、sprite 缓存原子交换、`.gfx`/`.yml`
  编辑的 TTL 指纹感知，以及拖拽回写与图标解析的 read action 修复。
- 适配 **Paradox Chronicle 3.0.2**。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.1.0.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.0) 下载。
