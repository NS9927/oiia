# Oiia 1.1.0

Rebuilds all script parsing on Paradox Chronicle's PSI and aligns the
technology tree preview with the game's tree layout.

## Highlights

- **PSI-only parsing**: hand-written text fallback parsers and the regex `.gfx`
  sprite scan were removed; all Paradox-script structure parsing goes through
  PLS (Chronicle) PSI.
- **Technology tree mirrors the game**: folder technologies are split into
  connected trees by `leads_to_tech`, with grid spacing, axis and slot size
  read from the matching gridbox in `countrytechtreeview.gui`.
- **Stability round**: background-thread parsing with auto refresh, atomic
  sprite cache swaps, TTL fingerprinting for `.gfx`/`.yml` edits, and read
  action fixes for drag write-backs and icon resolution.
- **Paradox Chronicle 3.0.2** support.

## Download

Install `oiia-1.1.0.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.0).
