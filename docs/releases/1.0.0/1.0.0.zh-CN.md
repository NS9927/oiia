# Oiia 1.0.0

Oiia 首个正式版本：面向 IntelliJ IDEA 的钢铁雄心 IV 模组开发工具包。

## 重点

- **国策树预览**：图标加载、前置连线、互斥连线、悬停详情与源码跳转。
- **科技树预览**：文件夹分组、图标加载、路径连线、悬停详情与源码跳转。
- **GUI 预览**：HOI4 `.gui` 文件的精灵、文本、布局与元素详情。
- **地图预览**：省份/州/国家/战略区域着色，可选颜色与边界模式。
- **Paradox Language Support 集成**：HOI4 项目推断、资源根、本地化与精灵解析。

## 下载

在 IntelliJ IDEA 的 **设置 | 插件 | ⚙ | 从磁盘安装插件…** 中安装
`oiia-1.0.0.zip`，或从
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.0.0) 下载。
