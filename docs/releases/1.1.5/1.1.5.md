# Oiia 1.1.5

Adapts to Shadow's HOI4 workspace location and Paradox Chronicle 3.0.2.

## Highlights

- **Shadow playset sync** now reads and writes
  `%APPDATA%\Posdaca\Hearts of Iron IV` (Shadow's HOI4 workspace at the time).
- **Paradox Chronicle 3.0.2** support (settings types moved to
  `icu.windea.pls.base.settings`, `ParadoxDefinitionElement` to
  `icu.windea.pls.lang.psi`, and `searchIcon` to `searchImage`).

## Download

Install `oiia-1.1.5.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.5).
