# Oiia 1.1.2

New GFX tool window, a round of map-preview fidelity and UX work modelled on
the hoi4modutilities reference, and a memory overhaul that fixes an IDE freeze
when previewing large maps.

## Highlights

- **New GFX tool window**: opening a `.gfx` file shows a grid of every sprite
  it declares, rendered from the resolved textures, with tooltips and
  double-click source navigation.
- **Map color sets**: `Terrain`, `Controller`, `Manpower`, `Victory Points`,
  `Resources`, `State Category`, `Province Type` and `Continent`, alongside the
  existing region fills.
- **Map timeline selector**: game bookmarks become timeline points; dated
  owner/controller changes inside state histories are applied and the fills are
  recoloured as of the selected date.
- **Map issue panel**: data-integrity warnings are listed, tinted red on the
  map and can be clicked to locate the region.
- **Impassable states and demilitarized zones**: red boundaries and a diagonal
  hatch overlay, with the matching state detail rows.
- **Locate field and `Export` action**: jump to any state/province/country/
  region, and render the whole map into a PNG.
- **Map labels** now anchor to each region's mass-weighted pixel centroid with
  seam-aware wrap correction, screen-fixed fonts and adaptive ink.
- **Decoupled toolbar selectors**: color set and view mode combine freely.
- **Memory overhaul**: fixes an IDE freeze (`OutOfMemoryError` storm) on large
  maps; GFX texture decoding gets a 192 MB budget.

## Download

Install `oiia-1.1.2.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.2).
