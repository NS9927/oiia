# Oiia 1.1.1

Technology folders now match the game's tab order.

## Highlights

- **Side-by-side technology folders**: folders are laid out horizontally (the
  next folder to the right of the previous one) in the game's tab order,
  instead of stacked vertically; each folder's trees stack vertically inside
  its own column.

## Download

Install `oiia-1.1.1.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.1).
