# Oiia 1.1.9

Adapts to Paradox Chronicle 3.0.4. Focus and technology names, icons and
descriptions are read through its new locale-aware definition API, and the Gradle
wrapper moves to 9.8.0.

## Highlights

- **Paradox Chronicle 3.0.4**: the singular `getPrimaryImages` /
  `getPrimaryLocalisations` / `getPresentableName` accessors it removed are replaced
  by the locale-aware `getRelatedImages` / `getRelatedLocalisations` /
  `getPresentableNames` ones, so focus quick docs and the technology preview keep
  resolving their names, icons and descriptions — this time in your configured
  display language.
- **Paradox Chronicle 3.0.4 is required**: 1.1.9 no longer runs against 3.0.3.
- **Build toolchain**: Gradle wrapper 9.8.0.

## Download

Install `oiia-1.1.9.zip` via **Settings | Plugins | ⚙ | Install Plugin from
Disk…** in IntelliJ IDEA, or grab it from the
[GitHub Release](https://github.com/NS9927/oiia/releases/tag/v1.1.9).
